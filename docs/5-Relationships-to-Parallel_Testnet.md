# 05 – Relationship to Parallel TestNet

## Current stage

Parallel TestNet (especially Phase 0 – Ethical Kernel + basic governance) is still under active design and early implementation.  
Therefore, AIC-For-NPO currently remains a **design and documentation** effort.

## Intended future relationship

When runnable components of the Ethical Kernel and governance evaluation (Allow / Deny / NeedHuman) become available:

- Templates and patterns in this repository should be expressible as test cases or scenarios on Parallel TestNet.
- Non-profit decision processes described here can serve as realistic workloads for testing refusal, auditability, and human-gating behavior.
- Feedback from actual non-profit use can help refine the kernel and governance mechanisms.

## Design rule

No component developed under AIC-For-NPO should bypass or weaken the Ethical-from-kernel direction of the main project.  
If a suggested NPO practice conflicts with core AIC principles, the practice should be adjusted or explicitly marked as divergent.
